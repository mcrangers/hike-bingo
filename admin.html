How do I get a GitHub key?
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Resource owner: mcrangers. Repository access: Only select repositories → hike-bingo.
  3. Permissions → Repository → Contents: Read and write. Set the expiry past the hike date.
